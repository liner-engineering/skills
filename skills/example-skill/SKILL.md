# Example Skill

## When to use
The user asks how a skill in this repo should look, or you are creating a new one.

## Steps
1. Copy this directory to `skills/<new-name>/` and rename `name` to match the directory.
2. Rewrite `description` as "what it does + when to use it" (max 1024 chars).
3. Put helper files in `scripts/`, `references/`, or `assets/` and link them by relative path.
